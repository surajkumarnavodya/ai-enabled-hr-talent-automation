# Claude Code Skills Index

> Owner: [TENANT_CONFIGURATION_REQUIRED] | Status: Draft

This directory is reserved for project-specific Claude Code skills (packaged, reusable instruction sets invoked via the Skill tool), distinct from:

- `.claude/commands/` — slash commands for discrete tasks (add endpoint, add workflow stage, etc.)
- `.claude/rules/` — always-loaded conventions enforced on every task
- `prompts/` — AI agent/skill system prompts for the *application's* runtime agents (not Claude Code itself)

No project-specific Claude Code skills exist yet. When adding one, follow the same document-control and cross-linking conventions as `/docs`, and register it here with a one-line description.
